# 余梦期·前置篇《灯还亮着》

状态：内容草案，可直接作为开服首批剧情轮次使用。

## 一句话定位

玩家进入世界时，丧尸危机刚刚出现，梦屿的医疗、能源、警备、物流、重生管理和居民自治机构正在临时接线。“逐光会”此时只有一个刚被提出的名字、几条不稳定的通信线路和一份尚未写完的承诺。玩家会亲手参与它的创建过程，但是否正式成为逐光会成员仍由每名玩家自己决定。

## 与主线的关系

- 本篇不是第五个大阶段，而是“余梦期”的开场内容包，故事阶段仍使用 dreamingfishcore:afterdream。
- 开始点是危机爆发后的最初几天；结束点是逐光会完成首次公开救援、发布临时约章并维持住一条外缘通信线。
- 逐光会在本篇中确实善意、有效，玩家对它的信任来自亲眼看见和亲手参与。
- 权力集中、信息筛选、身份固化、承诺失效和稳定感染者争议都留给后续主线，不在开场提前揭底。
- 玩家可以加入逐光会、与其合作但保持独立，也可以只经营自己的生活。三种玩法都能继续留在世界中。

## 开场必须让玩家感受到的四件事

1. 危机是刚发生的：旧生活仍留下温度，警报、撤离和停电正在同时发生。
2. 逐光会是刚形成的：没有成熟总部、完整制度和万能物资，很多工作由现场的人共同决定。
3. 梦屿仍值得守护：医院会收治陌生人，救援不会按财富和身份排序，普通人的名字会被记录。
4. 玩家不是迟到的旁观者：联络站、避难所、观察室、路线和早期规则都可以由玩家实际建设。

## 内容轮次

轮次不绑定现实日期。服主在对应世界事实出现、下一包内容准备好后手动发布。这样可以根据服务器活跃度伸缩节奏，也不会因为玩家上线时间不同而错过唯一事件。

### R0：这不是演习

世界变化：

- 城市广播仍在播放互相矛盾的撤离通知。
- 梦屿终端只能收到短时、低质量信号。
- 新成立的应急联络组开始使用“逐光会”这个临时名称，但还没有正式约章和总部。

发布内容：

- 一条危机广播；
- 梦屿应急联络员的首次私信；
- “先找到安全落脚点”的轻量个人引导。

玩家行为：

- 寻找食物、床位、照明和第一处过夜地点；
- 与其他玩家会合或选择独自生存；
- 在终端回复是否愿意继续接收建设信息；
- 标记一处可能改造成公共联络站的建筑。

结算与后果：

- 不以“第一晚没有死亡”为硬性成功条件。
- 玩家选择的落脚点可以继续发展成聚落，也可以只作为临时地点。
- 未回复私信的玩家仍可自然参加后续建设。

### R1：先有一盏灯

触发建议：

- 至少一处玩家聚落已有稳定落脚点；或服主准备好预设联络站。

世界变化：

- 梦屿内部通信开始合并，但不同部门仍在使用各自频段。
- 逐光会需要一座由玩家维护的外围联络站，用于登记求救、物资中转和广播转发。

发布内容：

- 联络站建设需求；
- 白芷的医院收货与伤员转运说明；
- 一条说明“加入逐光会不是领取职位，而是承担一件公共工作”的回复。

玩家行为：

- 自行选址，或改造现有玩家建筑；
- 提供电力、照明、床位、储物、基础医疗区和通信设备；
- 建筑玩家决定空间布局，工程玩家保证供能，探索玩家寻找缺少的零件；
- 给联络站取一个玩家自己的名字。

可保留的选择：

- 建在交通方便的公开地点：接应效率高，后续更容易受到尸潮压力。
- 建在隐蔽安全的地点：防守更容易，但转移距离和信息延迟增加。

结算与后果：

- 将建筑区域登记为剧情场所，后续 NPC、广播和救援事件继续使用。
- 只验证核心功能，不要求复刻指定建筑蓝图。

### R2：第一批抵达者

触发建议：

- 联络站具备基础照明、床位、储物和可到达路线。

世界变化：

- 一批从附近撤离点转移的居民遭遇丧尸，队伍中有伤员，也带着部分医疗物资。
- 逐光会尚无足够人手独自完成接应，请玩家参与。

发布内容：

- 接应地点和大致抵达方向；
- 白芷的分流说明；
- 接应结束后的实名救援记录。

玩家行为：

- 战斗玩家清理路线并掩护转移；
- 探索玩家侦察替代路线；
- 建筑与后勤玩家在联络站准备床位、食物和医疗区；
- 记录玩家保存幸存者姓名、出发地和途中损失；
- 玩家自行决定先护送伤员、先搬运关键物资，或分队同时处理。

结算与后果：

- 无论结果是否完美，故事继续。
- 伤员优先会提高医疗 NPC 的信任，但可能损失部分物资。
- 物资优先会改善下一轮建设条件，但幸存者会记住等待时间。
- 若接应失败，后续通过另一名幸存者、遗留终端和逐光会复盘提供必要信息。

这一轮的叙事目的，是让玩家亲眼确认：逐光会的成员确实在救人，玩家自己的建筑也确实救下了人。

### R3：逐光

触发建议：

- 第一批接应事件已经结算。

世界变化：

- 临时联合指挥机制第一次公开发布完整名称：“人类逐光联合会”。
- 组织仍然很小，玩家联络站被列为最早的民间协作节点之一。

发布内容：

- 成立广播；
- 临时约章；
- 玩家对加入方式的个人回复。

临时约章的三条开场承诺：

1. 救援不以财富、职业价值和完整身份资料排序。
2. 尚未完成正式登记、暂时无法撤离的人仍属于救援对象。
3. 紧急调度权必须保留记录，并在危机受控后交还居民自治体系。

玩家行为：

- 选择加入逐光会、保持独立协作，或暂不表态；
- 建造会议区、公告墙、物资登记区或当地分站；
- 讨论本聚落愿意承担的公共工作；
- 保存临时约章和最初广播原件。

结算与后果：

- 选择“加入”会立即写入服务端的逐光会成员身份；选择独立或暂不表态不会加入。
- 加入只改变组织身份、称呼、内部消息和后续参与入口，不强制玩家进入职业或感染阵营。
- 独立协作者仍会收到公共求援，也拥有批评和监督逐光会的空间。
- 建造联络站、参加救援或提高 NPC 好感度都不会自动把玩家登记为成员。
- 玩家以后仍可通过联络员私信加入或退出；退出不抹除既有贡献，也不取消公共救援和主线参与权。
- 保存原始约章会在后续“承诺是否被重新解释”时成为有效证据。

### R4：保持信号

触发建议：

- 联络站通信已经稳定，外缘救援承诺已经公开。

世界变化：

- 梁朔从外缘扩岸过渡社区接入断续信号。
- 他本可撤离，却留下维持医院冷库、供水、避难所通风和社区广播。
- 旧世界企业正在关闭服务器并要求优先保护工业设备；梁朔已把部分能源转给居民设施。

发布内容：

- 梁朔的首次短信；
- 梦屿侧中继检修引导；
- 一份供电切换记录和一份仍待撤离人员名单。

玩家行为：

- 检查梦屿侧中继、提供替代电源或修复零件；
- 在“立即派人接应”和“先稳定路线与通信”之间形成社区意见；
- 保存梁朔发来的维修日志、居民姓名和预登记片段；
- 回应梁朔是继续留守、立即撤离，还是按风险分批转移。

结算与后果：

- 没有唯一正确答案。立即接应更有人情温度，但风险高；先修线路更稳妥，但外缘设施继续承压。
- 梁朔不会在这一轮直接抵达梦屿。他会先送走能够撤离的居民，自己继续保持信号。
- 玩家是否保存原始记录，将影响后续能否证明他和其他留守者的身份连续性。

### 可选轮次 E1：通兰回声

用途：

- 当后续医疗或救援内容尚未准备好时，用一轮低成本通信剧情延长开场节奏。

世界变化：

- 尉迟南从通兰天文台恢复一段旧科研链路。
- 他首先提供天气、污染和远距通信数据，而不是立刻讨论外星文明。

玩家行为：

- 校准一处公共天线或时间同步设备；
- 决定是否为远距观测保留少量能源；
- 阅读一段无法确认来源的重复信号，但不被要求作出结论。

叙事边界：

- 这一轮只能种下“异常信号仍被保存”的伏笔，不能确认信号来源。
- 尉迟南承认风险属于所有人，因此玩家有权限制广播和能源使用。

### R5：隔离线以内

触发建议：

- 第一批救援完成，医院或观察区可用。

世界变化：

- 出现第一名由剧情控制的疑似感染患者；如果恰好有真人玩家感染，可以替换演出对象，但不能要求真人配合表演。
- 当前证据确实显示感染具有危险性，逐光会建立最初的检测、隔离和治疗流程。

发布内容：

- 白芷的观察区建设需求；
- 江晚按“已知事实、合理推测、未知和风险”整理的说明；
- 一份带时间、地点和观察条件的病例记录模板。

玩家行为：

- 建设或完善观察室、缓冲区和可沟通窗口；
- 提供防护、照明、药品、床位与清洁物资；
- 决定是否允许家属远距离沟通、是否公开患者姓名、何时发布未经验证的信息；
- 在患者仍能交流时听完其陈述，同时保持必要防护。

结算与后果：

- “谨慎隔离”和“承认患者人格”可以同时成立。
- 不在本轮展示长期稳定感染结论，只留下连续观察比单次检测更可靠的工作习惯。
- 玩家对患者、证据和隐私的处理方式，比单纯的短信好感度更能影响白芷与江晚的态度。

### R6：路还没有断

触发建议：

- 外缘中继与初期医疗准备已经完成。

世界变化：

- 逐光会与玩家完成第一次有限规模的外缘接应。
- 一部分居民安全进入梦屿协作区，证明“等待无法立即撤离者”不是空话。
- 梁朔因仍有居民和设施需要维持，再次选择留下；他的信号在最后一刻仍然存在。

发布内容：

- 接应结果广播；
- 梁朔的“第一批人已经走了”私信；
- 第一条正式世界历史记录。

玩家行为：

- 参与路线防守、接收、登记和医疗分流；
- 为获救居民提供临时住房；
- 把联络站、救援名单和逐光会临时约章共同存档；
- 讨论下一轮应优先扩大救援、加强防守还是完善感染医疗。

结束状态：

- 逐光会拥有一个被玩家参与建成的联络节点、一次真实救援、一个仍待兑现的外缘承诺和一套尚不成熟的感染流程。
- 玩家已经有理由信任它，也已经拥有监督它的原始记录。
- 服主发布下一内容包后，余梦期主线自然继续，不需要重新解释玩家为何突然卷入故事。

## 玩家可承担的行为类型

| 玩家偏好 | 在前置篇中的有效行为 | 世界如何承认 |
| --- | --- | --- |
| 建筑 | 联络站、避难所、观察室、会议区、居民住房 | 建筑登记为剧情场所，后续事件继续使用 |
| 战斗 | 清理接应路线、守住撤离点、护送队伍 | 救援记录、NPC 态度、下一轮安全程度 |
| 探索 | 找路线、中继、备用能源、遗留日志 | 新地点、替代方案和原始证据 |
| 工程 | 供电、通信、净水、冷藏与修复 | 设施状态和外缘信号质量 |
| 后勤 | 食物、药品、床位、运输与储存 | 救援容量和资源结余 |
| 社交 | 安置新人、主持讨论、协调冲突 | 社区记录、NPC 评价和公共决定 |
| 调查 | 保存广播、名单、时间戳与不同来源 | 后续承诺争议和身份核验依据 |
| 自由生存 | 建家、交易、旅行，不参与主线 | 不受惩罚，可在任意后续轮次加入 |

## 失败与补救原则

- 建筑被破坏：保留“第一次联络站失守”的历史，允许在新地点重建。
- 接应失败：记录伤亡与原因，通过另一名幸存者、遗留终端或后续小队补足必要信息。
- 中继未修复：梁朔改用低带宽广播，信息更少但主线不断。
- 原始记录未保存：后续仍可通过居民证词和梦屿端残片交叉恢复，只是证明成本更高。
- 玩家意见分裂：把分歧写入社区历史，不用投票强行制造唯一正确立场。

## 晚加入玩家

- 首次登录先收到当前世界状态摘要，不重播已经结算的唯一事件。
- 已完成的联络站、医院和档案室承担实体化教学作用。
- NPC 只向新人补发其实际能够知道的公共信息；私人谈话和个人好感内容仍需自己建立。
- 新人可通过维修、安置居民、整理记录和下一次接应补上参与感，不需要追赶完整任务清单。

## 最低开服内容与后续发布

开服当天至少准备：

- R0、R1 的私信与广播；
- 一处可由玩家选择或改造的联络站区域；
- R2 的接应事件骨架；
- 白芷、梦屿应急联络员两个可投递私信的 NPC 配置。

后续可以按开发进度依次发布：

- R2 与 R3：第一次救援和逐光会正式成立；
- R4：梁朔与外缘中继；
- E1：尉迟南通信支线；
- R5 与 R6：第一例疑似感染和有限规模外缘接应。

每个轮次都应产生看得见的建筑、居民、记录或关系变化，使前置篇本身构成完整可玩的开服故事。
