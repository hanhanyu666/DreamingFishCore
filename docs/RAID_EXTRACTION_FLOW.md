# 搜打撤：撤离流程设计（第 3 步收尾）

> 第 3 步的选点逻辑已经做完（`ExtractionSelector` + `ExtractionService`）。
> 这份文件定的是**玩家真正撤离**那一段的口径——它牵到玩家状态与结算，
> 所以先把规则写死再写代码。

## 一、怎么触发撤离

**站在撤离点范围内读条。**

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 触发范围 | 默认 3 格（可配） | 太大会让人"隔墙撤离"，太小会踩不准 |
| 读条时长 | 默认 5 秒（100 tick，可配） | 不用右键的原因：搜打撤的张力来自"暴露自己等待"，一秒完成会让撤离毫无风险，也不给别人伏击的时间窗 |
| 打断条件 | 离开范围 / 死亡 / 换维度 | 走开就中断，进度清零重来 |
| 受伤是否打断 | **默认不打断**（可配 `interrupt_on_damage`） | 若默认打断，被远程怪摸一下就读不完，撤离会变成运气；想硬核就打开 |
| 多人 | 各自独立计时，不共享进度 | 组队撤离应当是"每人都得站住"，不是一个人站住全队走 |
| 计时位置 | **服务端**每 tick 检查玩家位置与进度，客户端只显示进度 | 与现有"服务端权威 + 快照包"的惯例一致 |

实现要点：玩家所在维度、与撤离点坐标的水平距离、连续满足的 tick 数三者都要记在服务端状态里；
进度下发需要一个**自定义快照包**（会改线格式 → 必须提升 `PROTOCOL_VERSION`）。

## 二、撤离成功之后

1. **保留背包**（战利品带走，这是搜打撤的意义），传送到主世界（overworld）的指定坐标
   （配置 `exit_position`，缺省用世界出生点）。
2. 玩家从"本局参与者"名单里移除。
3. 聊天栏给结算小结：对局号、撤离点、带回物品件数（可选显示按 `spawn_cost` 汇总的价值；
   **出售价归 EconomySystem，这里不重复定义**）。
4. 记进对局记录：`extracted: [{玩家 UUID, 撤离点 id, 游戏内时间}]`，供以后统计与运营对账。

## 三、限次撤离点（车辆那种）

- `max_uses` 递减，**减到 0 后本局永久关闭**（符合"单次撤离点"的设定），并在状态里体现（提示语/外观）。
- **不冷却重开**：一局内用掉就是用掉。
- **新局恢复**：`max_uses` 随 `raid new` 重置（数据属于本局，不属于世界）。

## 四、没撤离就死 / 掉线

| 情况 | 处理 | 理由 |
| --- | --- | --- |
| 死亡 | **战利品丢失**：交给现有**尸体流程**（`DeathCorpseManager`）接管，本局带不回 | 死亡有代价是搜打撤的核心惩罚，且项目已有成熟的尸体机制，不另造一套 |
| 掉线 | **保留背包与位置**，重新登录仍在图内继续；给 5 分钟宽限 | 掉线多半是网络问题，没收背包既过罚也容易被误判为作弊处理 |
| 对局已结束还在图内 | 按"未撤离"处理：留在原处，背包不动（下一局开始时视为在场玩家） | 避免玩家被传送来传送去 |

## 五、整局何时结束

- **主口径：服主手动 `/dreamingfish raid end`**（现在就是这条路，已经会清战利品并还原容器）。
- **可选自动结束**（默认关闭，配置打开后满足任一即结束）：
  1. 时间到（`raid_time` 默认 1800 秒）；
  2. 所有参与者要么已撤离、要么已死亡；
  3. 撤离人数达标（配置）。
- 结束时依次：清本局填的战利品容器并还原原有内容（**已实现**）→ 按需清理本局刷出的怪 →
  把对局记录归档进 history（**已实现**）→ 限次撤离点等本局状态丢弃。

## 六、实现清单（按顺序做）

1. **本局参与者名单**：谁在这一局里（进入对局/撤离/死亡/掉线各自怎么记账），存进对局记录；
2. **撤离点运行时状态**：每个点的读条进度（按玩家）、`max_uses` 余量；
3. **读条判定**（服务端每 tick）+ **进度快照包**（提升 `PROTOCOL_VERSION`）；
4. **撤离执行**：传送到 `exit_position`、移出参与者名单、写结算记录与聊天小结；
5. **死亡钩子**：接进现有的死亡/尸体流程，把玩家标为"未撤离"；
6. **自动结束条件**（默认关闭）；
7. 测试：读条判定的纯函数（范围/打断/计时）单测 + gametest（造两个模拟玩家，一个站住撤离、
   一个走开中断）；**记得在 finally 里清理模拟玩家**（项目里已经踩过共享世界被污染的坑）。
