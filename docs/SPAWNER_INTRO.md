# 刷怪箱与「尸潮区域」功能介绍

> 面向服主/管理员/玩家的介绍版。完整判定顺序、验证方式与边界见
> [尸潮区域与刷怪箱](HORDE_AREA_AND_SPAWNER.md)，
> 设计决策见 [ADR 0042](adr/0042-horde-areas-are-a-location-flag.md)。

## 一句话

**刷怪箱**是一个放在**尸潮区域**里、按批次刷怪、打完给奖励的可配置方块；它是服主布置尸潮玩法的工具，**创造模式专属**。

## 一、怎么获得

- **只在创造模式物品栏**里拿得到。
- **没有合成配方**，**破坏它也不掉落**（掉落表为空）——刻意的：能合成或回收就会变成玩家囤积、搬运、重复刷奖励的道具。
- 外观有 **4 套**，可随时在界面里切换。

## 二、部署三步

1. **圈一块尸潮区域**：任务地点可以标记成尸潮区域
   （`/dreamingfish task_location horde on <地点名>`，`off` 取消）。
   - 尸潮区域是**三维盒子**（X / Y / Z 都判），和私人领地只看 X / Z 不是一回事；
   - **区域太薄（不足 5 格高）时命令会提醒**。
2. **在区域内放刷怪箱**：创造模式右键打开配置界面（也可给 2 级权限的管理员开）。
3. **配好后走进去**：有**生存或冒险模式**玩家进入检测范围，它自动开始工作
   （创造与旁观不算，服主可以从天上布置）。

## 三、可配置项

所有数值由**服务端**夹取，客户端提交的任何内容都当作不可信输入。

| 项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 刷的怪 | `dreamingfishcore:siege_zombie` | 任意实体 id | 界面里可直接输入，另附常用预设 |
| 检测范围 | 32 格 | 4–128 | 判定"附近有没有合格玩家"的水平半径 |
| 刷怪半径 | 8 格 | 1–64 | 以刷怪箱为中心的随机落点半径 |
| 每批数量 | 3 | 1–32 | 一批刷几只 |
| 刷怪冷却 | 600 tick（30 秒） | 20–24000 | **从上一批全部死亡开始计时** |
| 批次 | 3 | 1–64 | 一共刷几批 |
| 红石控制 | 关 | — | 开启后必须持续有红石信号才工作 |
| 剿灭自毁 | 关 | — | 开启后剿灭结算完就自我销毁 |
| 固定线索 | 关 | — | 开启后在剿灭结算时给区域内合格玩家各发一条线索 |
| 线索编号 | 0（不发放） | ≥0 | 线索的旧整数编号（见 `clues.json` 里的 `legacyId`），界面填编号即可 |
| 奖励经验 | 0 | ≥0 | 走本模组的等级系统 |
| 奖励梦鱼币 | 0 | ≥0 | 走 EconomySystem 入账 |
| 奖励物品 | 空 | ≤16 条，每条 ≤64 | 背包塞不下就掉在脚下 |

## 四、运行规则

- **启用三条件**（同时满足才工作，方块显示"工作中"）：
  1. 位于**开启尸潮开关**的任务地点内；
  2. 检测范围内有**生存或冒险模式**玩家（创造与旁观不算）；
  3. 勾了红石控制时，必须持续有红石信号。
- **刷怪节奏**：
  - 全新的一台在首次启用时**立刻**刷第一批；
  - 之后每一批都要等**上一批全部死亡**才开始计冷却，冷却到了再刷下一批；
  - 批次刷满且场上清空 = **剿灭达成**。
- **剿灭结算**：结算瞬间给**区域内**的生存/冒险玩家发奖励（与任务地点结算口径一致：
  按在场，不按最后一击）。
- **每台刷怪箱对每个玩家只发一次**奖励，跨轮次保留。不自毁的刷怪箱会等一个冷却后重开一轮，
  所以它可以反复用来做活动，但**不能反复领奖**。

## 五、界面与权限

| 操作 | 效果 |
| --- | --- |
| 普通右键（有编辑权限：创造模式或 2 级权限） | 打开配置界面 |
| 普通右键（无编辑权限） | 聊天栏显示完整参数、当前状态，以及"为什么没在工作" |
| 界面里的「换外观」 | 循环切换外观（4 套） |
| 界面里的「确认」 | 提交正在编辑的那一格并关闭界面 |

> **不要用"潜行 + 右键"开界面。** 原版在潜行且手持物品时会跳过方块交互去放手里的方块
> （`MultiPlayerGameMode#performUseItemOn` 的 `isSecondaryUseActive` 分支），
> 玩家会以为界面打不开——所以这里统一用普通右键。

## 六、常见坑

- **界面说"不在尸潮区域内"**：先看**高度**。地点是三维盒子，人在区域上方或下方
  （例如机器放在 Y=-60、而区域只有 Y=-61）就不算在区域内。
- **重新选定地点会重置尸潮开关**，需要重新 `horde on`。
- 检测"有没有玩家"只认生存/冒险模式；创造模式站在旁边不会触发。
