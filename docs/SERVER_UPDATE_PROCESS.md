# DreamingFish 标准服务器更新流程

当服主明确要求执行一次服务器模组更新，并提供需要更新或替换的模组后，默认完整执行以下流程；服主对当次更新提出的“不发布”“不重启”等要求优先。

1. 接收并确认本次需要更新、替换的模组以及更新器版本号和更新日志。
2. 将文件先上传到远程临时目录，核对大小与 SHA-256 后，分别替换正式服模组和远程更新器 source；清理同一模组的旧版本，其他模组不动。
3. 确认正式服与更新器 source 中的文件一致后，执行更新器扫描并发布新的更新器版本。
4. 更新器版本发布成功后，在正式服执行：`say 服务器将在1分钟后重启更新模组，请各位鱼友重启客户端。`，并从日志确认公告实际发出。
5. 等待一分钟，使用 `stop` 优雅关闭正式服；确认进程退出、端口释放后重新启动，并核对 `Done`、Java PID、tmux、实际端口、新模组加载记录和新增崩溃报告。

上传失败或校验不一致时停止后续操作；扫描与发布之间不得继续改动 updater source。整个流程结束后清理远程临时上传文件。
