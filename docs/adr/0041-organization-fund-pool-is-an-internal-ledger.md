# 组织资金池采用内部账，只进不出

EconomySystem 的账户 API 以**玩家**为单位（`EconomySystemApi.forPlayer` + `accounts().debit/credit`），既没有组织账户，也没有任何写领地的接口。因此组织资金池不可能是它的第二个账户。

选定做法：资金池是本模组的**内部余额**。入账靠成员从自己的梦鱼币账户 `debit` 进来，出账只用于系统扣费（聚居地过滤装置的维护费），解散时余额全额退给会长。**不提供取现入口**，也不支持组织之间转账。

这样做的代价是组织无法把余额花在玩家身上；收益是彻底消除了"谁能动这笔钱"的权限争议与挪用风险，也不必依赖经济模组提供尚不存在的组织账户能力。如果将来 EconomySystem 开放组织账户，应当把资金池迁移过去，而不是继续维护两份账。
