# 线索可信度由交叉验证决定

线索不采用“记录时间越长就必然越真”的二元规则。观察时长仍是重要指标，但必须与样本数量、观察条件、来源和其他证据共同决定证据强度。短期记录可以准确描述局部事实，却可能作出超出样本的错误结论；长期记录也可能带有解释偏差或被篡改。

随记本记录线索提出的主张、支持证据和已发现矛盾，不直接显示系统判定的真假。这样调查玩法要求玩家理解证据之间的关系，而不是按时间排序领取答案。

作者使用“证据包”组织承担核心论证责任的内容，但该分类不向玩家显示。居民日记、广播、留言等氛围线索可以负责前期误导，也可以在后期暗示和佐证正确内容；它们只是不作为不可逆结局的唯一门槛。所有线索在呈现上保持同等的可调查价值，避免玩家只按系统标签收集所谓核心内容。
