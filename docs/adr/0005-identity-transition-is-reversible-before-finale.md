# 终局前身份转换双向可逆

幸存者可以通过自然感染或诱导转化进入不稳定感染状态，再由团队完成稳定治疗；感染者保留通过解药疗程恢复为幸存者的途径。转换消耗资源、设施和协作成本，并受到冷却限制。最终行动开始后锁定有效参与者身份。

双向可逆可以避免偶然感染或早期集体选择永久锁死结局，同时保留身份决定的重量。选择昂贵疗程而非即时切换，是为了让身份仍代表玩家经历和社会关系，而不是开门时更换的工具职业。

治疗按状态分层：幸存者使用抑制剂降低感染值，不稳定感染者接受成本较低的早期逆转疗程，稳定感染者接受成本较高的重构疗程。正规疗程不采用随机失败，身份决定的风险来自资源、设施、时间和协作成本。
