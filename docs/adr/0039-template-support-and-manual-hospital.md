# 模板维护使用可恢复余量，医院建筑由人工验收

服主确认把“分裂次数”统一为“模板重建余量”，并增加每个 MC 游戏日提交 2 个金苹果、恢复 5 点余量的医疗服务。余量表示稳定重建储备，能够通过医疗维护恢复部分数值，不等同已经永久丢失的人格信息。原有存档字段和余额保留；死亡服务与界面统一遵循“正余量可完成最后一次标准重建”的规则，物品保留仍需足额支付。

为使单人开发环境能够完整验收，医院剧情采用阅读公告、固定人数门槛、人工验收建筑、一次 NPC 复查，不建立建筑识别、电力模拟或真人病例等待流程。按服主后续确认，医院小章随余梦期自动开放，替代最初的手动启动；已有余梦期存档在更新重启后接入，第一阶段不提前发布。世界建设成果、个人复查和实际治愈各自记录；建筑验收和世界切章仍由服主操作。每日维护从临时接待时期开放，随后跨章节持续提供。

玩家背包和属性分属两份存档，因此不能只记录“今日已领”后扣物，也不能只扣物再依赖一次性加点。先将扣物后的背包和付款收据一起保存、核对，随后将余量和每日记录一起写入属性文件；未完成收据在认证登录或下次操作时重试。运行时属性保存失败恢复内存余额和每日记录，保留已付款收据。日期使用主世界游戏日期，回拨不会产生新的领取机会。
