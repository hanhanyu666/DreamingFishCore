# 主线使用对话解锁的阶段引导任务与双进度

主线保留任务系统，但不采用每日委托、奖励列表或点击接受的传统入口。每个故事阶段定义一组阶段引导任务，玩家只有在实际经历包含对话提示的NPC交谈或终端消息后才解锁对应任务；终端保存原始语境和个人任务状态，任务完成必须来自服务端验证过的实际行为，客户端勾选不能制造完成事实。

每名玩家的个人调查进度等于其已完成阶段任务数占该阶段任务总数的比例。同一任务由不同玩家分别完成和记录，不使用“任意一人完成便全服完成”的共享目标模型。玩家在当前阶段首次解锁任一阶段任务后成为阶段剧情参与者，社区平均调查进度是所有这些参与者个人进度的算术平均；完全未接触主线的自由生存玩家不进入分母。

两项进度都按故事阶段分别计算和归档，只表示个人与社区接触剧情内容的程度，不表示线索真假、结论正确率或阶段自动完成。进度较高或长期停滞时，NPC可以通过玩家终端自然提示交流对象或建议社区讨论，但是否讨论、讨论什么、是否投票、何时发布运营轮次及切换故事阶段仍由玩家和服主决定。
