# 任务地点使用故事系统专用区域

> 状态：已被 ADR-0035 部分替代。任务地点仍由故事系统定义，但 `BUILDABLE` 地点现在允许叠加 EconomySystem 的玩家私人领地；`PROTECTED` 地点继续保持本 ADR 的独立保护语义。

任务地点由 DreamingFishCore 独立定义为固定地图中的官方三维区域，不复用 EconomySystem 的玩家领地。任务地点为地图保护、任务结算时的在场玩家收集和后续局部尸潮提供共同坐标依据，但不拥有任务结果，也不会因玩家进入而自动推进故事。

玩家经济领地解决所有权、成员和长期建设权限；任务地点解决作者布置的固定剧情空间，两者的生命周期、权限和失败影响不同。强行复用会让主线依赖另一个持续开发的模组，并把不需要的经济、领地主人和 Buff 语义带入剧情任务。

第一版只支持官方地点、管理员两点选区、JSON 热重载和基础结构保护。`PROTECTED` 地点中的生存玩家临时切换为冒险模式，离开时恢复生存模式，OP 权限不绕过这一模式转换；`BUILDABLE` 地点保持生存模式，只遵守 TNT、岩浆和打火石点燃下界传送门的禁令。创造、旁观和原本就是冒险模式的玩家保持原模式但仍收到场景提示，事件保护继续作为服务端兜底。玩家建筑登记为剧情场地、复杂授权、快照回滚和破坏性演出继续延后，避免阻塞 EP01 纵切片。
