# 玩家建筑可以自愿登记为剧情场地

建筑者可以把自己的建筑登记为医疗中心、会议厅、避难所、哨站、防御阵地等剧情场地，并配置NPC站位、入口、互动设备和尸潮方向等锚点。数据驱动内容引用场地类型与锚点，不写死玩家建筑坐标；没有可用玩家场地时使用官方地点兜底。

登记必须由拥有相应建筑权限的玩家主动完成，场地也可以随时停用。剧情事件默认不得破坏方块、引发爆炸或火灾、修改容器，后续领地系统负责提供所有权与基础保护，事件只能使用场地主人明确授权的能力。

第一版场地授权只有“纯叙事”和“无建筑破坏的防守事件”两类。防守事件可以生成NPC、尸潮和战斗目标，但禁止方块与容器修改、爆炸破坏、火焰蔓延、农田踩踏和怪物破坏建筑。需要永久改变地形或建筑的演出只能使用官方地点，除非未来另行实现可靠的快照与回滚机制。
