# 感染身份用等级承载、传播复发用独立时间窗承载

四种感染身份里，幸存者/不稳定感染者/稳定感染者在语义上是**递进的突变阶段**，继续由存档里的 `infectionLevel`（0/1/2）承载；而传播复发是稳定感染者的**临时**状态，因此用独立的到期 tick 表达，不引入等级 3。

如果把复发编成等级 3，所有既有的 `>= 2` 比较（复核话术、重构疗程准入、感染上限 200 的判定）都会把复发误判成"更严重的另一种身份"，而它实际含义是"回到可传播态"。正交字段让这些比较保持正确，也让旧存档（0/1/2）无需迁移脚本。代价是"当前身份"必须由一个统一入口（`InfectionIdentity.of` / `PlayerAttributesData.getInfectionIdentity`）解析，不能各处自行拼装。
