# 主线不使用传统任务界面

守望梦屿的主线通过NPC对话、可回看的对话记录、随记本、调查板、广播和世界现场进行剧情内引导，不提供接受任务、目标清单、完成弹窗或阶段进度条。服务端可以静默记录经过验证的世界事实，用于后续回应、奖励与历史，但不向玩家暴露内部推进条件；传统任务系统只服务于教程、日常委托和非主线内容。

这一选择以较高的发现和回忆成本换取沉浸感与玩家自主解释空间。为避免玩家因现实遗忘而断线，NPC应能自然重述已公开信息，个人对话记录保留原始语境，但系统不自动整理出标准答案或待办步骤。

NPC原话可以由作者对少量人物、地点、时间和行动信息使用颜色与粗体强调，格式随原始对话一起进入个人记录。强调文本仍不是可接受或可完成的任务，也不得作为系统判定真相的标签。

玩家终端可以把已经获得的不同调查成果聚合为“社区调查态势”进度条，并保存由对话提示产生的个人引导记录。这些界面用于回忆和组织调查，不显示故事阶段完成率、隐藏条件数量或真相正确率；个人勾选状态不具有世界推进权威。
