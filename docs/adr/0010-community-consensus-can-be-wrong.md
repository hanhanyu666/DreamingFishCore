# 社区共识可以错误并继续推进世界

公共调查板允许玩家围绕已分享证据自由发起表决。获得大多数有效投票者支持的主张成为当前社区结论，并作为后续 NPC 对话、广播与人工运营内容的依据；它可以与客观真相不符，也不会因为错误而阻止游戏继续推进。

有效投票者是投票期限内自愿提交选票的玩家，未投票者作为弃权不进入多数比例分母。自由生存玩家不被强制参与，但与主线玩家拥有相同的自愿投票权。世界事实不因投票改变，最终不可逆提交仍遵循终局预警规则。

社区结论默认至少需要两名不同的有效投票者。人数不足时提案保持待决，不判定通过或否决，也不冻结自由生存与其他调查活动；最低人数由服务端配置，以适配实际服务器规模。

投票期限只在服务器有玩家在线时累计，到期后自动结算。发起者在已有选票后不能提前结束或删除提案；管理员可以因违规内容取消，但必须保留带取消原因的审计归档。允许的期限档位和默认值由服务端配置。

个人选票不向其他普通玩家公开，投票进行期间任何人都不能查看实时票数。投票结束后，只有实际提交选票的玩家能够查看汇总数据；未投票者不能查看票数，但仍可能通过广播和 NPC 回应知道社区形成了怎样的公开结论。服务端可以保留管理员审计记录。

赞成与反对票相等时，投票归档为“社区未形成共识”，不产生社区结论，也不设置发起者、管理员或组织NPC的决胜票。玩家可以继续调查并在获得新证据后创建新版提案，原投票不自动无限延长。
