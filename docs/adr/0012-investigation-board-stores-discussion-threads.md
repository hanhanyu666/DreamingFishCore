# 公共调查板保存轻量讨论帖

玩家可以在公共调查板创建持久讨论帖，填写标题和正文、引用个人随记本中的线索、接收其他玩家的短评论并发起投票。帖子、评论、引用证据、投票结果和时间信息由服务端保存并归档，供后来者阅读，也供服主编写下一运营轮次的 NPC 对话与广播。

NPC与系统可以提出值得讨论的争议并指向调查板，但不得自动代替玩家创建讨论帖或发起表决；是否把一个问题提升为社区议题，必须来自玩家主动行为。

调查板不扩展为完整社区论坛，不包含与剧情调查无关的复杂版块、富文本或社交功能。持久讨论用于补足普通聊天易丢失、难以归属于具体议题的问题。

讨论帖在开启投票时冻结标题、正文和初始证据作为提案快照，防止投票后偷换主张。投票期间仍可继续评论、补充新线索，玩家也可以在截止前修改自己的选票；若要改变核心主张，必须创建保留旧版归档的新提案。
