# 故事定义与世界运行状态由统一StoryManager管理

旧 `StoryStageManager` 同时混合配置定义、玩家完成集合和客户端视图，后来新增的世界状态模块又与它平行持有阶段概念。重构后只保留 `gameplay/story_system`：`StoryManager` 加载数据驱动定义并管理 `StoryWorldState`，配置与世界运行数据分离，阶段使用稳定字符串ID、数字编号和显示名称，旧整数接口只作为暂时兼容入口。

客户端同步不再携带其他玩家姓名和UUID，只发送阶段定义、任务成功或失败、在场人数及当前玩家个人状态。旧客户端完成包可以暂时记录个人兼容完成，但不能结束共享任务、发布运营轮次或切换故事阶段；这些变化只能通过服务端权威接口与服主命令发生。
