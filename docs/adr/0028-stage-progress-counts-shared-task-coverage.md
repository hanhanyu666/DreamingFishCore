# 阶段进度使用全服任务覆盖率与个人参与覆盖率

主线使用由运营轮次激活、再由NPC对话和终端消息自然提供个人引导的阶段任务。玩家终端显示两项进度：全服阶段任务进度等于已经由任意玩家或团队完成的不同阶段任务数占本阶段任务总数的比例，每项任务全服只计一次；个人调查进度等于该玩家在场完成的不同阶段任务数占相同总数的比例。不再计算所有剧情参与者个人进度的平均值。

同一任务不要求所有玩家重复完成。多人合作任务正式结束时，全服进度增加一次，并以服务端判定结束的瞬间为准，让任务区域内所有生存或冒险模式玩家分别取得带结果的个人记录；旁观模式、管理员调试身份、范围外与离线玩家不计入。不再按伤害、治疗、运输或最后一击统计贡献。任务成功与正常失败都计入双进度，失败使用红色状态显示且不能正常重开。两项进度都不表示线索真假，也不自动发布讨论、投票、运营轮次或故事阶段。

阶段任务可以依赖幸存者与感染者的实际能力差异，但任务标题和目标不得直接显示“仅某身份可完成”。NPC措辞、环境反应和玩家尝试只提供弱引导，让社区自行发现适合的分工；这种隐藏条件必须有可观察反馈，不能成为没有解释的系统硬墙。

两项进度的分母只包含当前阶段已经随运营轮次发布的任务，不包含未来或尚未发布的内容。服主发布新轮次并增加任务后，个人与全服进度允许因分母扩大而下降；终端应以新情况或新增待查事项解释变化，不向玩家泄露未来任务总量。
