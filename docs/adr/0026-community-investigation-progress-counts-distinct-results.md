# 社区调查态势按不同调查成果聚合

玩家终端显示全服共享的社区调查态势，但它不按全体玩家完成个人引导项的比例计算。进度只来自当前阶段中不同的有效调查成果，同一发现或行动结果全服只计一次；新玩家加入、自由生存玩家不参与和多人重复处理相同请求都不会使进度倒退或虚增。

该进度用于提示社区已经积累了多少可供集中讨论的材料，而不是故事阶段完成率、证据正确率或自动推进条件。接近就绪时NPC可以通过终端建议玩家交流，玩家仍自由决定是否创建帖子、讨论什么以及是否发起投票；服主可以随时根据真实讨论发布内容或切换故事阶段，不存在被系统指定的阶段投票入口。

只有已经分享到调查板、由NPC公开确认或形成公共事件记录的成果才计入态势。个人随记本和私人对话中的未公开发现不增加全服进度，也不能通过进度变化向其他玩家泄露；多人公开同一成果仍只计算一次。

社区调查态势按故事阶段分别计算。服主切换阶段后开启该阶段的新态势，旧阶段的成果、最终态势和相关讨论永久归档，不删除也不继续混入新阶段的进度。
