# 后续剧情采用人工运营和服务端热重载

玩家可以自由发起社区讨论和投票，系统负责保存讨论文本、引用证据、投票结果及相关世界状态。服主根据实际社区进展编写或修改数据驱动的 NPC 对话、广播与后续内容，再通过服务端热重载发布，不要求客户端更新模组。

主线不要求系统理解任意自由文本并全自动生成响应。未来接入大语言模型时，它只作为可选的内容起草工具；人工审核后的服务器数据才具有发布和推进权威。该方式保留玩家行为的不可预演性，同时让世界回应维持人物一致性与剧情质量。

社区结论形成后进入“等待世界回应”的运营轮次，服主在合适时间发布下一轮内容，不对玩家承诺固定现实日更新。等待期间自由生存、建筑、探索和普通事件照常进行，NPC可以使用预设过渡状态说明相关组织正在讨论或准备回应。

对投票的最低回应只要求 NPC 或广播谈论玩家实际讨论的话题并表达角色立场。并非每次投票都必须自动产生新任务、政策变化或永久剧情分支；服主可以只更新内容，也可以在重要节点另行加入事件。
