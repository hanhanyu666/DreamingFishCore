# 现代医院 · Minecraft Java 1.21.1

三层白色现代医院，蓝色玻璃窗、入口雨棚和医疗十字。配有接待柜台、候诊座椅、急诊侧门、检查床、住院床位、柜子、照明和连接三层的楼梯，前院设救护车通道与绿化。只使用原版方块，无需 WorldEdit。

## 安装与放置

1. 将 `ModernHospital-1.21.1.zip` 原样复制到目标存档的 `datapacks` 文件夹。单人存档通常为 `.minecraft/saves/存档名/datapacks`；服务器为对应世界目录下的 `datapacks`。
2. 进入世界，以有权限执行命令的玩家运行 `/reload`。
3. 找一块空地，在地面站好，运行：

   ```mcfunction
   /place template modern_hospital:hospital ~-23 ~-2 ~8
   ```

   医院生成在你南侧（世界 +Z），主入口朝北（-Z），不随玩家朝向旋转。地基从脚下两格低的位置开始，前院地面与脚下地面齐平。主入口约在你南侧 18 格处。

也可以指定西北角地基坐标：

```mcfunction
/place template modern_hospital:hospital 100 63 100
```

此例完整覆盖 X=100～146、Y=63～85、Z=100～142，前院地面 Y=64。放置区域的区块需要已加载；在目标地附近执行，若提示未加载，可提高服务器视距后重试。

## 放置范围

完整范围为 **47×23×43（X×Y×Z）**，包含空气，会清除范围内原有方块。请先备份存档，首次在创造模式测试世界放置；原版命令没有撤销功能。建筑不自动贴合地形，适合平地。

## 文件与验证

- `ModernHospital-1.21.1.zip`：直接安装的数据包，格式版本 48。
- `modern_hospital.nbt`：独立原版结构文件，DataVersion 3955。也可放入存档 `generated/modern_hospital/structures/hospital.nbt`，以同一 `/place template` 命令加载。
- 生成脚本：项目 `tools/generate_hospital.py`，运行可重新生成两个文件。

已检查数据包目录、NBT 编码、建筑边界、床的完整性和楼梯净空；未启动 Minecraft 进行实际加载或视觉验收。

这是建筑文件，尚未绑定 DreamingFishCore 的医院剧情地点、NPC 或医疗服务。现有医院剧情配置保持原样。
